# The Algorithm Mail — Android app

A thin Capacitor shell around the Mailflare web app
(mailflare.yasuuuu-official.workers.dev) with the owner's branding:
name "The Algorithm", brand logo as launcher icon, dark splash screen.

Pushing to `main` runs the GitHub Actions workflow, which builds the APK
and attaches it to a GitHub Release (`TheAlgorithmMail.apk`).
